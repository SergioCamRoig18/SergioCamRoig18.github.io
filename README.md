# Sergio Camacho Roig — Software Engineering Portfolio

Personal web portfolio deployed at **[sergiocamroig18.github.io](https://sergiocamroig18.github.io)**, featuring a **Call of Duty: Advanced Warfare** inspired tactical HUD interface built with **Vite + React + TypeScript**.

## Highlights
- **Bilingual (EN / ES):** Instant language switching with `localStorage` persistence and keyboard shortcut (`L`).
- **Tactical HUD Navigation:** Continuous vertical flow with sticky scroll-spy top bar (`Q` / `E` section jump) and `Ctrl + K` command palette.
- **Featured Deployments & After Action Reports:** Detailed architecture case studies for **Zubopedia-Web**, **Votify** (.NET 9 / Blazor / PostgreSQL), and **GitHub HUD Engine**.
- **Interactive Loadout Inspector:** Explorable tech stack that cross-filters projects directly without arbitrary skill percentages.
- **Live Telemetry Ready:** Consumes the `HudSnapshot` schema with safe local fallback.
